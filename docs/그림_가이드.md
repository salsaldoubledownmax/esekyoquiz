# 값 그림 만들기 가이드

스테이지 문제를 만든 뒤 `images` 폴더에 넣을 그림을 그릴 때 쓰는 규칙.
원작(Profile Perfect) 화면 여러 장을 분석해 정리한 **표현 패턴**이며, 그림 자체는 원작을 베끼지 않고 새로 그린다.

## 1. 값의 종류별 표현 패턴

| 패턴 | 언제 쓰나 | 원작 예 | 우리 게임에서 그리는 법 |
|---|---|---|---|
| **사물 하나** | 이름이 있는 물건·동물·장소 | 정어리, 고래, 거북, 개구리 | 대상 하나를 크게, 가운데에. 실루엣만 봐도 구별되게 |
| **수량 반복** | "많다/적다", "몇 명" 같은 양 | Social Behavior: 물고기 떼(많음) vs 2~3마리(적음), Crowd: 사람 1~6명 | 같은 작은 그림을 개수만큼 한 덩어리로 모아 그림. 개수 차이를 크게(예: 1·3·6). 한 SVG 안에 반복 |
| **별·점 개수** | 등급·점수·순위 | Rating ★★ / ★ | 같은 기호를 가로로 N개. 개수가 곧 값 |
| **색 원** | 색깔 속성 | Color 노랑 원, 유니폼 빨강·초록 원 | 그 색으로 칠한 동그라미 하나(테두리 있음) |
| **기호 배지** | 약자·등급 코드 | 보호 등급 LC / EN / VU | 동그란 진한 배지 안에 짧은 글자 1~3자. 배지 색으로도 구별 |
| **작은 장면** | 서식지·장소처럼 배경이 의미인 값 | 야자수 섬(해변), 강, 바다 | 바닥(물·풀·모래) + 대표 사물 1개의 작은 풍경 |
| **얼굴** | 사람이 값일 때 | 농부: 캐릭터 얼굴 | 머리 모양·색이 다른 동그란 얼굴 |
| **글자 알약** | 숫자+단위, 그림으로 나타내기 어려운 값 | Lifespan "6 years", "90 years" | **그림을 만들지 않는다.** `images`에 안 적으면 게임이 크림색 알약 안에 글자로 보여 줌 |

> 원작에는 한 칸에 두 값을 대각선으로 나눠 넣는 칸도 있지만, 우리 게임 규칙에는 없으므로 쓰지 않는다.

## 2. 그림 스타일 (모든 그림 공통)

- 캔버스 `viewBox="0 0 64 64"`, 그림은 가운데에 꽉 차게(여백 4~6).
- 진한 갈색 테두리 `#4a3b33`, 굵기 3, 모서리·끝 둥글게(`stroke-linejoin/linecap: round`).
- 채우기는 파스텔. 볼터치(연분홍 타원)·하이라이트(흰 타원)로 귀엽게.
- 그림 안에는 글자를 넣지 않는다(기호 배지 제외). 이름은 보기 창에서 글자로 함께 나옴.
- 같은 행 안의 그림끼리는 색·실루엣이 확실히 달라야 함(1학년이 헷갈리지 않게).
- 게임에서 정답·보기 그림은 모두 같은 크기(48px)로 줄어 보이므로 작은 디테일은 생략.

## 3. 그림이 쓰이는 곳

1. 정답 칸: 그림만(글자 없음).
2. 보기 창 타일: 그림 + 이름.
3. 인물 칸 스티커: 맞힌 값의 그림이 작게(22px) 캐릭터 둘레에 붙음 → 작아져도 알아볼 수 있어야 함.
4. 단서 문장: 보기 이름 앞에 작은 그림(22px) + 밑줄 + 행별 색.
5. 시작 화면: 둥실거리는 장식.

## 4. stage.js에 넣는 법

```js
images: {
  "수학": "images/math.svg",
  "물고기 떼": "images/fish-many.svg",   // 수량 반복: 한 파일에 여러 마리
  "별 2개": "images/star-2.svg",          // 별 개수
  // "6살" 같은 글자 값은 적지 않음 → 알약 글자로 표시
}
```
