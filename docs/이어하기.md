# 이어하기 메모 (2026-10-29 학교 PC → 집 PC)

학교 행사용 Profile Perfect 방식 추리 퍼즐 게임 "돌아온 세교퀴즈". 이 메모만 읽어도 이어서 작업할 수 있게 정리함.
자세한 규칙·결정은 `docs/계획서.md`(특히 11장 결정 1~45번).

## 파일 구조

| 파일 | 내용 |
|---|---|
| `index.html` `style.css` `game.js` | 게임 코드 (순수 HTML/CSS/JS, 외부 라이브러리 없음) |
| `stage.js` | 스테이지 데이터만. 맨 위에 작성법 주석. `avatars`(장소 그림), `reveal`(축하 화면 진짜 이름), 행의 `label`, `submitUrl` 포함 |
| `images/` | 값·장소 그림(SVG). 행사판 16개 + 예전 예시 7개(수학 등, 지금은 안 씀) |
| `sounds/` | 교사가 준 소리 파일 4개(정답·오답·다 맞힘·폭죽). 크기·자르기는 `game.js`의 `SOUND_FILES` |
| `fonts/Hakgyoansim_GeurimilgiR.ttf` | 학교안심 그림일기체 (6.3MB) |
| `tools/solve.js` | 퍼즐 검사(답이 하나인지, 찍지 않고 끝까지 풀리는지). `node tools/solve.js stage.js tools/rules.js` |
| `tools/rules.js` | 단서 문장의 뜻을 코드로 적은 목록. **단서를 고치면 같이 고치고 검사 다시 돌림** |
| `tools/serve.js` | 미리보기 서버. `node tools/serve.js . 4180` → http://localhost:4180 |
| `.claude/launch.json` | Claude 앱 미리보기 창용 설정(위 서버를 4180으로 띄움) |
| `docs/계획서.md` | 전체 계획·결정·점검 결과 |
| `docs/그림_가이드.md` | 값 그림 그리는 패턴과 스타일 규칙 |
| `docs/구글시트_연결/` | Apps Script(`Code.gs`)와 설치 안내서 |

## 남은 일

1. 실제 휴대폰(안드로이드·아이폰)에서 새 판 한 판씩: 소리 크기, 그림, 한 줄 이름, 축하 화면 확인.
2. 선생님이 들어 보고 소리 크기·길이 더 조절할지 결정(`SOUND_FILES` 숫자만 고치면 됨).
3. 장소 그림이 장소를 너무 쉽게 알려 주는지 학생 반응 보고 결정(덜 닮게 바꿀 수 있음).
4. 학생 몇 명에게 시험 → 푸는 시간·하트 잃는 정도 보고 난이도 조절.
5. 안 쓰는 예시 그림 7개(`images/math.svg` 등) 지울지 결정.
