# 구글 시트로 응모 받기 — 설치 안내

다 맞힌 학생이 적은 **학년·반·번호·이름·뽑혀야 하는 이유**가 선생님 구글 시트에 한 줄씩 쌓이게 하는 방법이에요.
**개인 Gmail 계정**으로 한 번만 설정하면 돼요. (약 10분)

---

## 1. 시트 만들기

1. 개인 Gmail로 로그인한 상태에서 [sheets.new](https://sheets.new) 를 열어 새 스프레드시트를 만들어요.
2. 왼쪽 위 제목을 예: `추리퍼즐 응모` 로 바꿔요.
   (시트 탭 이름은 신경 쓰지 않아도 돼요. 첫 응모가 들어올 때 **"응모"** 탭이 자동으로 만들어져요.)

## 2. Apps Script 붙여 넣기

1. 메뉴 **확장 프로그램 → Apps Script** 를 눌러요.
2. 열린 화면의 `Code.gs` 안에 있는 내용을 **모두 지우고**, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣어요.
3. 위쪽 **저장(디스크 모양)** 을 눌러요.

## 3. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포** 를 눌러요.
2. 왼쪽 톱니바퀴 **유형 선택 → 웹 앱** 을 골라요.
3. 아래처럼 정하고 **배포** 를 눌러요.

   | 항목 | 고를 것 |
   |---|---|
   | 설명 | 아무거나 (예: 응모 받기) |
   | 다음 사용자 인증 정보로 실행 | **나(선생님 Gmail)** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

4. **액세스 승인** 창이 뜨면:
   - 선생님 Gmail 계정을 고르고
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)** 을 누른 뒤 **허용** 을 눌러요.
   - 선생님이 직접 만든 스크립트라서 나오는 경고예요. 이 스크립트는 **이 시트에 줄을 추가하는 일만** 해요.
5. 배포가 끝나면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 **복사**해요.

## 4. 게임에 주소 넣기

`game/stage.js` 맨 아래의 `submitUrl` 에 복사한 주소를 붙여 넣어요.

```js
  submitUrl: "https://script.google.com/macros/s/여기에_복사한_주소/exec",
  submitNotice: "적은 내용은 행사 추첨에만 쓰고, 행사가 끝나면 지워요.",
```

- `submitUrl` 을 비워 두면(`""`) 응모 칸이 나오지 않고 게임만 돼요.
- `submitNotice` 는 응모 칸 아래 작은 글씨로 나오는 안내 문구예요. 학교 방침에 맞게 고쳐 쓰세요.

## 5. 시험해 보기

0. 먼저 **로그아웃한 창(시크릿 창)** 에서 웹 앱 주소를 열어 보세요.
   `{"ok":true,"message":"응모 받을 준비 완료"}` 가 보이면 학생들도 보낼 수 있는 상태예요.
   **"액세스 거부됨 / 액세스 권한 필요"** 가 보이면 아래 "자주 생기는 문제" 첫 줄을 보세요.
1. 게임을 끝까지 풀고 축하 화면에서 다섯 칸을 적어 **제출하기** 를 눌러요.
2. 버튼이 **"제출했어요!"** 로 바뀌면 성공이에요.
3. 시트에 **응모** 탭이 생기고 `제출 시각 | 학년 | 반 | 번호 | 이름 | 뽑혀야 하는 이유` 줄이 들어왔는지 확인해요.
4. 시험으로 넣은 줄은 지워도 돼요(머리글 줄은 남겨 두세요).

## 자주 생기는 문제

| 증상 | 원인·해결 |
|---|---|
| 주소를 열면 **"액세스 거부됨 / 액세스 권한 필요"**, 게임은 "보내지 못했어요" | 배포의 **액세스 권한이 "나만"** 으로 되어 있어요. **배포 → 배포 관리 → 연필(수정)** 에서 "액세스 권한이 있는 사용자"를 **모든 사용자** 로 바꾸고, 버전은 **새 버전** 을 골라 **배포**. 주소는 그대로예요 |
| "보내지 못했어요" 가 계속 나와요 | ① 인터넷 연결 확인 ② `submitUrl` 이 `/exec` 로 끝나는지 확인 ③ 배포의 "액세스 권한"이 **모든 사용자** 인지 확인 |
| Code.gs 를 고쳤는데 반영이 안 돼요 | **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** 를 해야 반영돼요. 주소는 그대로예요 |
| 학교 계정(Workspace)으로 만들었더니 학생 휴대폰에서 안 돼요 | 학교 관리자가 외부 공개를 막아 둔 경우예요. **개인 Gmail** 로 다시 만들어 주세요 |
| 같은 학생이 여러 번 들어 있어요 | 게임은 한 판에 한 번만 보내지만, 다시 도전해서 또 깨면 또 보낼 수 있어요. 추첨 전에 이름·번호로 중복을 정리해 주세요 |

## 개인정보 관리

- 학생 이름·학년·반·번호를 모으므로, 행사 안내에 **수집 목적(추첨)과 보관 기간** 을 알려 주세요.
- 시트는 **선생님만** 볼 수 있게 두세요(공유 링크를 만들지 않기).
- 행사가 끝나면 시트를 지우고, Apps Script 의 **배포 관리 → 배포 보관처리** 로 주소를 닫아 주세요.
